find: Search for files that meet a desired criteria
  find ./ -size 1033c ! -executable: find a file somewhere under the inhere directory and has following  properties:  
     human-readable   • 1033 bytes in size  • not executable
  find / -type f -user bandit7 -group bandit6 -size 33c :   find a file  somewhere on the
        server and has all of the following properties:
          owned by user bandit7   owned by group bandit6  33 bytes in size
  find -name "filename": Find file by its file name
  find / -user bandit20:   find all  file  owned  by user = bandit20
  find / -perm -u=s -type f 2>/dev/null: 
               lists files with the SUID bit enabled  
  
   find / flag1.txt -exec cat /home/igor/flag1.txt \;	
  
  
   find / -user igor -perm -4000 -exec ls -ldb {} \; 2>/dev/null	
	find / -user igor:  look in the system all  filles owned by user igor 
		  -perm -4000: files with setuid bit  4000
		  
		  Setuid allows to run a file with the the permissn of the file owner
	exec ls -ldb {} \;  : for every  file that was found run the command ls -ldb <file
	ls -ldb <file>
פירוש:
-l – רשימה ארוכה (long listing)
-d – לא נכנס לתוך תיקיות (אם זה תיקיה, רק מציג אותה עצמה)
-b – מציג תווים מיוחדים ב־backslash escape
	
	
	סיכום

       הפקודה מוצאת כל קובץ בבעלות igor עם setuid במערכת הקבצים, ואז מציגה מידע מפורט עליהם תוך התעלמות משגיאות גישה.
        ה שימושי למשל למעקב אחרי קבצים שיכולים להוות סיכוני אבטחה אם הם בעלי הרשאות גבוהות.
